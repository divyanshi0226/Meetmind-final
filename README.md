# MeetMind 🤖🎥

## 📌 Project Overview

**MeetMind** is a full-stack application designed to enhance online meeting experiences by combining automation, backend intelligence, and a modern frontend. The project includes a **Google Meet Bot**, a **backend service**, and a **frontend web application**.

This repository demonstrates real-world full-stack development practices, including deployment fixes, CORS handling, and scalable project structure.

---

## 🧩 Project Structure

```
MeetMind/
│
├── Google-Meet-Bot/        # Bot for automating Google Meet actions
├── meetmind-backend/       # Backend server (API, DB connection, logic)
├── meetmind-frontend/      # Frontend web application
│
├── .gitignore              # Git ignore rules
├── package.json            # Project dependencies and scripts
├── package-lock.json       # Dependency lock file
└── README.md               # Project documentation
```

---

## 🚀 Key Features

* 🤖 **Google Meet Bot** for automated meeting interactions
* 🌐 **Backend API** with proper deployment handling
* 🖥️ **Frontend Web App** deployed on Render
* 🔐 CORS configuration for secure frontend-backend communication
* ☁️ Cloud-ready architecture (Render + Railway)

## ▶️ How to Run Locally

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/your-repo-name.git
cd MeetMind
```

### 2️⃣ Backend Setup

```bash
cd meetmind-backend
npm install
npm start
```

### 3️⃣ Frontend Setup

```bash
cd meetmind-frontend
npm install
npm start
```
